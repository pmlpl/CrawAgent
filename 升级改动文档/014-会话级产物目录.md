## 〇、价值

- **改动前**：CrawAgent 没有"会话文件夹"概念。产物按**类型**全局堆：`save_to_file` 默认 `subdir=""` 写 `output/` 根，所有会话的 `.py/.js/.md/.txt` 全堆一起（实测 `output/` 根有 `_haowallpaper_script_full.py`、`Fa_fn.js`、`CSDN_布洛妮娅_*.md`、`_mem_dump.txt` 等混在一起）。`downloads/` 按 AI 临时起的 subdir 分（不对应会话）。用户在桌面（项目目录 `C:\Users\MOM\Desktop\学习项目\CrawAgent\` 在桌面下）看到一堆散文件，问"它没有自己的任务会话文件夹吗"。
- **改动后**：每个会话有独立产物子目录 `output/<会话标识>/`。`save_to_file` 默认写当前会话子目录；`run_custom_script` 注入会话子目录常量给脚本；前端可挂"打开本会话产物目录"按钮。会话间产物隔离，目录名可读（知道是哪个会话的产物）。

## 一、背景与问题

1. **save_to_file 默认写 output/ 根**：`file_tool.py:68` `subdir: str = ""`，`_resolve_file_path` 在 `subdir=""` 时直接拼 `output_dir / filename`。AI 不带 subdir 调用时，产物堆 output/ 根。
2. **run_custom_script 无会话归属**：`script_tool.py` 注入 `OUTPUT_DIR`/`DOWNLOADS_DIR` 绝对常量给脚本，但没注入会话子目录。AI 脚本按 OUTPUT_DIR 写文件，也落 output/ 根（或 AI 临时起 subdir）。
3. **工具层拿不到当前 session**：`@tool` 函数被 LangGraph agent 调用，agent 在 `turn_engine` 里跑，turn_engine 知道 session_id，但工具函数无状态、签名里没 session。需要一条通道把 session 传到工具层。
4. **_tmp 残留子目录（已治标）**：`_ensure_tmp` 原只清顶层文件（`glob("*")` + `unlink`，遇目录跳过），残留 `downloads/output/tools` 子目录。治标已随本规格提交（递归 `shutil.rmtree`）。
5. **命名困境**：会话标题有可读性但可能为空/含非法字符；session_id 是 hash 无可读性。需要"标题优先、id 兜底 + 非法字符过滤"策略。

## 二、目标

1. **会话上下文通道**：用 `contextvars.ContextVar` 存当前 session_id + 会话标题。`turn_engine` 调 agent 前设值（`current_session.set({id, title})`），工具函数读 `current_session.get()`。
2. **save_to_file 默认会话子目录**：`subdir=""` 时默认用当前会话标识作子目录（`output/<会话标识>/`）；AI 显式传 subdir 时覆盖（向后兼容，不破坏现有调用）。
3. **run_custom_script 注入会话常量**：脚本头部加 `SESSION_SUBDIR` 常量，AI 脚本可 `OUTPUT_DIR / SESSION_SUBDIR / "xxx.md"` 写到会话目录。
4. **会话标识命名策略**：会话标题优先（去非法路径字符、限长），无标题/新会话退回 `session_id[:8]` + 短时间戳。去重：同标题加 `-2`/`-3` 后缀。
5. **前端（可选，二期）**：会话侧栏项挂"打开产物目录"按钮，调后端接口在文件管理器打开 `output/<会话标识>/`。
6. **不做**：迁移历史产物（只影响新会话）；改 downloads/ 媒体目录（媒体按 subdir 分已有意义，不强加会话——除非用户要）。

## 三、方案设计

- **contextvar 通道**：新建 `crawagent/web/session_context.py`（或挂 `state.py`），定义 `current_session: ContextVar[dict|None]`。`turn_engine._emit` 或调 agent 的入口处 `token = current_session.set({"id": sid, "title": title})`，结束后 `current_session.reset(token)`。工具函数 `from crawagent.web.session_context import current_session` 读值。注意：LangGraph agent 调用是同步上下文，contextvar 在同线程内可透传；异步需确认 `asyncio` task 上下文复制（LangGraph 内部用 asyncio，contextvar 在同 task 内透传，跨 task 要 `contextvars.copy_context().run`——实施时验证）。
- **save_to_file 默认**：`file_tool.py` `_resolve_file_path` 里 `if not subdir: sess = current_session.get(); subdir = _session_subdir(sess) if sess else ""`。`_session_subdir` 做标题清洗 + 去重。
- **run_custom_script 注入**：`script_tool.py` 拼脚本头部时加 `SESSION_SUBDIR = {session_subdir!r}`（从 contextvar 读），AI 脚本用 `OUTPUT_DIR / SESSION_SUBDIR / "x.md"`。
- **命名清洗**：`re.sub(r'[<>:"/\\|?*]', '_', title)[:40]`；空则 `session_id[:8]`；同目录已存在不同会话加后缀去重（靠会话 id 区分，标题撞名加 `-短id`）。
