## 〇、价值

- **改动前**：CrawAgent 没有"会话文件夹"概念。产物按**类型**全局堆：`save_to_file` 默认 `subdir=""` 写 `output/` 根，所有会话的 `.py/.js/.md/.txt` 全堆一起（实测 `output/` 根有 `_haowallpaper_script_full.py`、`Fa_fn.js`、`CSDN_布洛妮娅_*.md`、`_mem_dump.txt` 等混在一起）。`downloads/` 按 AI 临时起的 subdir 分（不对应会话）。项目目录在桌面（`C:\Users\MOM\Desktop\学习项目\CrawAgent\`）下，指挥官在桌面看到一堆散文件，问"它没有自己的任务会话文件夹吗"。
- **改动后**：每个会话有独立产物子目录 `output/<会话标识>/`。`save_to_file` 默认写当前会话子目录；`run_custom_script` 注入会话子目录常量给脚本。会话间产物隔离，目录名可读（知道是哪个会话的产物）。

## 一、背景与问题

1. **save_to_file 默认写 output/ 根**：`file_tool.py` `subdir: str = ""`，`_resolve_file_path` 在 `subdir=""` 时直接拼 `output_dir / filename`。AI 不带 subdir 调用时，产物堆 output/ 根。
2. **run_custom_script 无会话归属**：`script_tool.py` 注入 `OUTPUT_DIR`/`DOWNLOADS_DIR` 绝对常量给脚本，但没注入会话子目录。AI 脚本按 OUTPUT_DIR 写文件，也落 output/ 根（或 AI 临时起 subdir）。
3. **工具层拿不到当前 session**：`@tool` 函数被 LangGraph agent 调用，agent 在 `turn_engine` 里跑，turn_engine 知道 session_id，但工具函数无状态、签名里没 session。需要一条通道把 session 传到工具层。
4. **_tmp 残留子目录（已治标）**：`_ensure_tmp` 原只清顶层文件（`glob("*")` + `unlink`，遇目录跳过），残留 `downloads/output/tools` 子目录。治标已随 commit b23853e 入库（递归 `shutil.rmtree`）。
5. **命名困境**：会话标题有可读性但可能为空/含非法字符；session_id 是 hash 无可读性。需要"标题优先、id 兜底 + 非法字符过滤"策略。

## 二、目标

1. **会话上下文通道**：用 `contextvars.ContextVar` 存当前 session（id + 标题）。`turn_engine` 调 agent 前设值，结束后 reset；工具函数读值。
2. **save_to_file 默认会话子目录**：`subdir=""` 时默认用当前会话标识作子目录（`output/<会话标识>/`）；AI 显式传 subdir 时覆盖（向后兼容，不破坏现有调用）。
3. **run_custom_script 注入会话常量**：脚本头部加 `SESSION_SUBDIR` 常量，AI 脚本可 `OUTPUT_DIR / SESSION_SUBDIR / "xxx.md"` 写到会话目录。
4. **会话标识命名策略**：会话标题优先（去非法路径字符、限长 40），无标题/新会话退回 `session_id[:8]`；同目录撞名加会话短 id 后缀区分。
5. **不做**：迁移历史产物（只影响新会话）；改 downloads/ 媒体目录（按 subdir 分已有意义）；前端改动（二期另立规格）。

## 三、方案设计

- **contextvar 通道**：新建 `crawagent/web/session_context.py`，定义 `current_session: ContextVar[dict | None]`（内容 `{"id": str, "title": str}`）。`turn_engine` 调 agent 入口处 `token = current_session.set(...)`，finally 里 `current_session.reset(token)`。注意：LangGraph 内部走 asyncio，contextvar 在同一 task 内透传；若 agent 内部 `create_task` 派生新 task，contextvar 默认复制快照（create_task 会拷贝当前 context），实施时验证跨 task 场景，不行就用 `contextvars.copy_context().run` 包裹。
- **save_to_file 默认**：`_resolve_file_path` 里 `if not subdir:` 读 `current_session.get()`，有值则 `subdir = _session_subdir(sess)`。`_session_subdir` 做标题清洗（`re.sub(r'[<>:"/\\|?*]', '_', title)[:40]`）、空标题退回 `session_id[:8]`。
- **run_custom_script 注入**：`_ALLOWED_HEADER` 加第 5 个 format 占位 `SESSION_SUBDIR = {session_subdir!r}`（从 contextvar 读，无会话为空串）。
- **边界与回退**：contextvar 无值（后台任务/worker 进程/测试直调工具）→ 行为与改动前完全一致（落 output/ 根），保证 run_custom_script 在分布式 worker 里照常工作。标题全为非法字符清洗后为空 → 退回 session 短 id。

## 五、验证方式

1. **_ensure_tmp 递归清理**：在 data/_tmp 造顶层文件 + 子目录（含嵌套文件）→ 调 `_ensure_tmp()` → 全部消失。专项测试 `test_ensure_tmp_removes_subdirectories`（已随治标补上并通过）。
2. **会话子目录默认**：设 `current_session` 后调 `save_to_file.func(filename="t.md", content="x")` → 文件落 `output/<会话标识>/t.md`；不设 contextvar 直调 → 落 `output/` 根（兜底与改前一致）。
3. **显式 subdir 覆盖**：设 contextvar 后调 `save_to_file(subdir="自定义")` → 落 `output/自定义/`，会话子目录不生效。
4. **run_custom_script 注入**：跑 `print(SESSION_SUBDIR)` 的脚本 → 输出当前会话标识；无会话时输出空串。
5. **命名清洗**：会话标题 `"a/b:c"` → 子目录名 `a_b_c`；40 字超长截断；空标题退回 session 短 id。
6. **全量回归**：`uv run pytest tests/ -q` 全绿（基线 + 新增）；前端未动不 build。
7. **端到端**：新会话让 AI 跑一个含 save_to_file 的任务 → `output/` 下出现以会话命名的子目录且产物在其中，根不再新增散文件。
