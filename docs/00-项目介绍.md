# 00 · 项目介绍

> 基于 LLM 的智能网页爬虫 Agent —— 你用自然语言下指令，它自己决定用哪个工具、怎么爬、怎么存。

## 一、这是什么

CrawAgent 是一个 **LLM 驱动的自主爬虫框架**。用户给出一个 URL 或任务描述（"抓取这本小说的全部章节"、"下载这个 B 站视频"、"这批壁纸帮我存下来"），由 DeepSeek 驱动的 Agent 自主规划并执行：选择工具 → 执行 → 检查结果 → 失败换策略 → 循环直到完成任务。

与 传统爬虫脚本 的本质区别：**不需要为每个站写代码**。通用站点直接靠工具组合 + 置信度自动升级；刁钻站点（字体加密、CSS 卡片、强反爬）由 Agent 现场写 Python 脚本攻克，并把成功脚本存进"站点档案"供下次复用。

## 二、核心能力

| 能力 | 说明 |
|------|------|
| 自主工具循环 | LangGraph `create_agent`，28 个工具，LLM 自主决策调用量（多数对话零工具调用） |
| 置信度自动升级 | 静态抓取结果评分 <60 → 自动切 Playwright 浏览器重抓，零 LLM 成本 |
| 防死循环中间件 | `ScriptForcerMiddleware`：连续 3 次失败强制写自定义脚本；总调用 30 次上限强制总结 |
| 兜底武器 | `run_custom_script`：Agent 现场写 requests + BS4 脚本，专治所有内置工具搞不定的站 |
| 站点档案 | 首次成功后保存策略/脚本/Cookie（`data/sites.json`），同站复用跳过分析 |
| 领域专用工具 | 微信读书（Cookie 认证）、抖音/B 站（免登录提取+下载）、壁纸站（CSS bg-image 卡片）、番茄小说（PUA 字体解密 + VIP 代理） |
| 会话持久化 | SqliteSaver 按 thread_id 存完整状态，重启后继续聊；会话删除前自动归档 JSON |
| 流式 WebUI | Vue 3 + WebSocket，token 级流式输出、工具轨迹、推理过程折叠展示、事件日志断线重放 |

## 三、技术栈

- **后端**：Python 3.11+ / LangChain 1.x（`create_agent` + middleware）/ langgraph（SqliteSaver checkpointer）/ FastAPI + WebSocket / Playwright / BS4 + lxml / fonttools（字体解密）
- **前端**：Vue 3 Composition API + Vite + vue-router / marked + DOMPurify / WebSocket
- **模型**：DeepSeek（OpenAI 兼容格式），支持多模型切换与思考深度分档（prompt cache 深度优化）

## 四、系统架构（一图流）

```
Vue 3 WebUI ──WebSocket── FastAPI (server.py)
                                │
                     LangGraph create_agent
                   （SYSTEM_PROMPT + 28 工具 + 双中间件）
                                │
        ┌───────────────────────┼───────────────────────┐
 TrimHistoryMiddleware   LLM (DeepSeek)        ScriptForcerMiddleware
 （token 裁剪，不污染持久态）  （prompt cache 命中）  （失败计数→强制自定义脚本）
                                │
                          28 个 @tool 工具
        crawl / browse / extract / list / save / query / social /
        wallpaper / weread / download / site_profile / script
                                │
        SQLite (crawagent.db + sessions.db) · sites.json · output/ · downloads/
```

## 五、快速开始

```bash
# 1. 安装依赖（Python 3.11+ / Node 18+）
uv sync --extra api --extra browser
playwright install chromium

# 2. 配置
cp .env.example .env    # 填入 DeepSeek API Key

# 3. 前端构建 + 启动
cd web && npm install && npm run build && cd ..
python -m crawagent.web.server
# → http://127.0.0.1:8000
```

开发模式（前端热更新）：终端 1 跑后端，终端 2 `cd web && npm run dev` → 5173 端口自动代理。
