### 结论

抖音无登录状态下受风控保护：
1. 页面通过 `_$jsvmprt` 加密下发数据，`RENDER_DATA` 无 `play_addr`/`aweme_id`
2. 出现验证码 iframe（rmc-nocaptcha），视频流地址带签名（a_bogus/X-Bogus）
3. 2026 年分享链接有效期缩短至 24 小时，私密/异常作品第三方工具无法解析

### 攻破方案：匿名 Cookie 自动获取（公开视频无需登录）✅ 已实测

**公开视频不需要登录**！抖音风控要求的是"浏览器指纹 + 新鲜匿名 cookie（ttwid 等）"，而非账号登录。项目已实现全自动链路（P8）：

```bash
# 方式一（推荐）：直接下载，自动获取匿名 cookie（全自动，无需登录）
curl -X POST http://localhost:8000/api/video/download \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.douyin.com/video/7636871210730523913"}'

# 方式二：手动拿匿名 cookie（可选，先取后存，可复用）
curl -X POST http://localhost:8000/api/auth/profile/anonymous \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.douyin.com"}'
# → {"success": true, "cookies_count": 38, "cookies_file": "C:\\Users\\MOM\\.crawagent\\profiles\\www.douyin.com\\cookies.txt"}
```

**实测结果**（2026-08-02）：
- 浏览器渲染一次自动收集 **38 个匿名 cookie**（ttwid / odin_tt / passport_csrf_token 等），全程无需登录
- yt-dlp 带匿名 cookie 提取到视频**全部清晰度格式**：最高 **1280x720 (h265) 高清直链**（另有 1024x576 h264/h265）
- 47.2 MiB MP4 下载成功，ftyp 魔数有效、可播放

实现原理：
- `ProfileManager.grab_anonymous_cookies`：Playwright 无头浏览器渲染站点，JS 风控自动种下完整匿名 cookie 集 → 转 Netscape cookies.txt
- `MediaDownloader.download`：遇到抖音 URL 且未提供 cookie 时**自动兜底**获取匿名 cookie → 交给 yt-dlp，一次调用完成下载

**什么情况才需要登录**（`POST /api/auth/login` 手动登录）：仅私密 / 好友可见 / 需会员的特定作品。公开视频一律无需登录。
