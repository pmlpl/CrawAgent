# 06 · 配置与运行

## .env 完整说明

配置文件在项目根目录 `.env`，由 `crawagent/config/settings.py`（Pydantic BaseSettings）自动读取。**绝对路径定位**——不依赖启动时的工作目录。

```ini
# ---- LLM ----
# 多服务商模型注册表（WebUI 设置页「模型」维护，JSON 数组），Key 按服务商共享：
# LLM_PROVIDERS=[{"name":"DeepSeek","base_url":"https://api.deepseek.com/v1","api_key":"sk-...","models":["deepseek-chat"]}]
# 为空时回退到下面的旧全局配置（兼容已有 .env）：
OPENAI_API_KEY=sk-xxxxxxxxxxxx        # 旧全局 Key（注册表为空时的回退）
OPENAI_BASE_URL=https://api.deepseek.com/v1
DEFAULT_MODEL=deepseek-v4-flash
# 思考深度: off / low / high / max（medium 会被映射为 high），默认 off
THINKING_DEPTH=off

# ---- 爬虫 ----
REQUEST_TIMEOUT=30                    # HTTP 超时（秒）
REQUEST_DELAY=1.0                     # 请求间隔
MAX_CONTENT_LENGTH=50000
FFMPEG_PATH=                          # ffmpeg.exe 路径（B站视频合并）
BILIBILI_COOKIE=                      # B站认证
LOCKED_CHAPTER_API=                   # VIP 章节代理 API（番茄小说），留空不启用
# 站点级 Cookie（微信读书 wr_vid + wr_ssk 等）不在此配置——随站点档案存在 data/sites.json

# ---- 存储（默认值，一般不用改） ----
# DB_PATH=data/crawagent.db           # 抓取内容
# SESSIONS_DB_PATH=data/sessions.db   # 会话检查点

# ---- LangSmith（可选） ----
LANGSMITH_API_KEY=
LANGSMITH_PROJECT=crawagent
LANGSMITH_TRACING=false

# ---- Token 控制 ----
HISTORY_MAX_TOKENS=8000               # 传给 LLM 的历史上限（不含 system prompt）
HISTORY_KEEP_RECENT_TURNS=3           # 滑动窗口保留轮数
TOOL_RESULT_MAX_CHARS=500             # 单条工具结果裁剪阈值
```

要点：
- `get_settings()` 返回单例；LangSmith 配置会同步注入 `os.environ`（LangChain 运行时直接读环境变量）
- 模型与 API Key 在 WebUI 设置页维护（`/api/models` 增删改），存入 `.env` 的 `LLM_PROVIDERS` JSON；改完自动失效 Agent 缓存，下次对话按新配置重建
- 对话页每条消息携带所选模型 ID（WebSocket `model` 字段），后端按模型解析其服务商的 Key/URL，Agent 按模型分别缓存
- API Key 只保存在后端 `.env`，任何接口都不返回明文（前端只看 `key_set`）；含 `*` 的值一律视为掩码不回写

## 启动命令

### 终端 CLI

```bash
# 安装依赖
uv sync                     # 核心依赖
uv sync --extra api         # + FastAPI
uv sync --extra browser     # + Playwright + 字体解密

# 运行
python -m crawagent.web.server   # 启动 WebUI
# -> http://127.0.0.1:8000
```

### WebUI

```bash
# 生产模式
cd web && npm run build                    # 构建到 web/dist
cd .. && uv run python -m crawagent.web.server
# -> http://127.0.0.1:8000

# 开发模式（热更新）
# 终端 1（后端）：
uv run python -m crawagent.web.server
# 终端 2（前端）：
cd web && npm run dev
# -> http://127.0.0.1:5173（/api 与 /ws 自动代理到 8000）
```

## 首次安装清单

1. 安装 Python 3.11+ 和 Node.js 18+
2. `uv sync` 安装 Python 核心依赖
3. `uv sync --extra api --extra browser` 完整安装（FastAPI + Playwright + 字体解密）
4. `playwright install chromium` 安装浏览器二进制（`browse_and_crawl` 工具需要）
5. 创建 `.env`，填 `OPENAI_API_KEY`（DeepSeek 平台获取）
6. （可选）配 `BILIBILI_COOKIE`（全局，B 站工具使用）；站点级 Cookie（如微信读书）在「站点档案」页按站点配置，或直接发给智能体保存
7. （可选）配 `LANGSMITH_API_KEY` 开启链路追踪
8. WebUI：`cd web && npm install && npm run build`，然后 `python -m crawagent.web.server`
9. （可选）配 `FFMPEG_PATH`（B站视频下载需要 ffmpeg 合并音视频）

## 站点级 Cookie（微信读书等）

站点凭据不属于全局配置——挂在对应站点的档案（`data/sites.json`）里，任何需要登录的站点都可以配：

1. 浏览器登录目标站，F12 → Application → Cookies，复制所需 Cookie（微信读书为 `wr_vid` 和 `wr_ssk`）
2. 在 WebUI「站点档案」页点"设 Cookie"粘贴（格式：`wr_vid=xxx; wr_ssk=yyy`），或直接把 Cookie 发给智能体，它通过 `save_site_profile(cookies=...)` 存进档案

Cookie 过期时工具返回 `[AUTH_FAILED]`，重新导出更新即可。

## 运行时数据

| 路径 | 内容 |
|------|------|
| `data/crawagent.db` | 抓取的内容记录（SQLite） |
| `data/sessions.db` | LangGraph 会话检查点（WebUI 会话持久化） |
| `data/sites.json` | 站点档案（策略/脚本/Cookie） |
| `data/font_cache/` | PUA 字体映射缓存（首次解密后复用，加速番茄小说类站点） |
| `output/` | 抓取**文本**产物（md/json 等），按 `{类型}/{域名}/{日期}/` 组织 |
| `downloads/` | 抓取**媒体**产物（图片/视频/音频），按站点子目录组织 |
| `logs/crawagent.log` | 运行日志（轮转） |
| `logs/*.json` | 删除会话时的归档纪要（自动生成，永久保留） |
