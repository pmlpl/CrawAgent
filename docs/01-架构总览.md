## 核心设计思想

1. **System Prompt 纯静态** —— 不含时间戳等动态内容，保证 DeepSeek prompt cache 每次命中，大幅降低 token 成本
2. **create_agent 原生循环** —— 不自建 tool loop，LLM↔工具循环由 LangChain 内部处理
3. **检查点持久化** —— SqliteSaver 按 `thread_id`（= session_id）存完整会话状态，进程重启后可恢复
4. **置信度自动升级** —— 提取结果 <60 分自动切 Playwright 浏览器重抓（规则启发式，零 LLM 成本）
5. **中间件治 token 与死循环** —— 双中间件各管一件事：
   - `TrimHistoryMiddleware`：半水位淘汰裁剪传给 LLM 的历史（超限时一次性淘汰到 max/2，此后窗口固定），但**不污染**持久化的完整 state
   - `ScriptForcerMiddleware`：累计 3 次工具失败 → 追加 SystemMessage 强制改用 `run_custom_script`；5 次失败 → 最强指令禁止一切内置工具；单轮总调用 30 次上限 → 强制输出最终答案。强制消息**追加到末尾而非插头部**，否则会打碎 DeepSeek 缓存前缀
6. **工具即插件** —— `@tool` 装饰器 + docstring 即工具规范，加新工具零样板代码
7. **工具是手段不是目的** —— SYSTEM_PROMPT 内置 TOOL USE JUDGMENT 决策树：问候/概念/选序号等多数对话零工具调用，只有"URL + 动作动词"才触发执行
8. **事件日志重放** —— 每轮事件 append 到内存日志，WS 断线重连按 cursor 从 0 重放，`done`/`error` 收尾事件永不丢失
