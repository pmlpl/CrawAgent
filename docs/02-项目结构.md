## 入口与依赖关系

```
web/server.py (WebUI)──> graph/agent.py ──> llm/model.py ──> DeepSeek API
                              │         ├──> tools/*（17 个工具）
                              │         ├──> middleware.py（token 裁剪）
                              │         └──> script_forcer.py（防死循环）
                              │
                              └──> config/settings.py（.env 单例 + 代理清理）
                                       └──> observability/metrics.py

web/ (Vue 3) ──WebSocket /ws/{id}──> server.py
             ──REST /api/*──────────> server.py ──> site_profile_tool / checkpointer
```

**关键路径**：Vue 前端 → `useChat.connect()` WS → `chat_ws()` → `_stream_turn()` → 工作线程 `_run_turn()` → `agent.stream(...)` → LLM 决定工具调用 → 工具执行 → 事件经 `_emit` 写日志+推队列 → 前端逐字上屏
