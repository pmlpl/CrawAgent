# CrawAgent Wiki

> 面向使用者的知识库 —— 不暴露内部安全实现细节，只告诉你「是什么、怎么用、出问题怎么办」。

## 这个 Wiki 是什么

`wiki/` 是 CrawAgent 的使用说明书，区别于 `docs/`（开发者内部文档）：

- **读者**：使用者、二次开发者、团队成员
- **目标**：把项目「能做什么、怎么用、扩展点在哪」讲清楚，不陷入源码细节
- **边界**：不写安全机制细节、不列完整 API 清单、不暴露目录结构全貌（防止信息泄露）

```
01-快速开始 → 02-核心概念 → 03-工具与技能总览 → 04-扩展能力 → 05-常见问题
```

- **01-快速开始**：5 分钟跑起来

## 使用约定

- Wiki 内容随版本演进，以 [更新日志.md](./更新日志.md) 为准
- 任何与实际行为不一致的描述以代码为准；发现偏差请反馈，我们会同步修订
- Wiki 不含密钥、不晒目录树、不贴源码片段——需要查源码请直接看 `docs/` 或仓库
