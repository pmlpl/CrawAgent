# 01 · 快速开始

> 5 分钟把 CrawAgent 跑起来，完成第一次对话。

## 环境要求

- Python 3.11+
- Node.js 18+（前端构建）
- [uv](https://docs.astral.sh/uv/)（Python 包管理）
- 可选：Playwright 浏览器内核（SPA/动态页面爬取需要）

## 一、安装

```bash
# 克隆后安装（editable 模式，改代码立即生效）
uv sync --group dev
uv sync --group browser   # 需要浏览器渲染时
uv sync --group api       # 需要 FastAPI Web 后端时
uv sync --extra dist      # 需要分布式爬虫时（Redis）

# 可选：浏览器内核
uv run playwright install chromium

# 可选：Android 逆向（不写入主依赖，避免冲突）
pip install frida frida-tools
```

## 二、配置

复制 `.env.example` 为 `.env`，填入必要字段：

```bash
cp .env.example .env
```

最少必填项：

| 变量 | 说明 | 示例 |
|------|------|------|
| `OPENAI_API_KEY` | LLM API Key（DeepSeek 平台获取） | `sk-xxxxxxxx` |
| `OPENAI_BASE_URL` | API 地址 | `https://api.deepseek.com/v1` |
| `DEFAULT_MODEL` | 默认模型 | `deepseek-v4-flash` |

其余字段保持默认即可。多服务商模型注册表 `LLM_PROVIDERS` 可在 WebUI 设置页维护，不必手改 `.env`。

## 三、启动

```bash
# 生产模式（前端已构建）
uv run crawagent start
# → http://127.0.0.1:8006
```

启动时会：

1. 加载 `.env`
2. 自动检测/下载/启动 Redis（分布式模式启用时；非分布式跳过）
3. 启动 FastAPI 服务
4. **不会**自动弹浏览器（需在 WebUI 设置页手动触发，或前端按钮一键打开）

环境变量可调：

| 变量 | 作用 | 默认 |
|------|------|------|
| `CRAWAGENT_PORT` | 端口 | `8006` |
| `CRAWAGENT_HOST` | 监听地址（`0.0.0.0` 时不弹浏览器） | `127.0.0.1` |
| `CRAWAGENT_NO_OPEN` | 禁止自动弹浏览器 | `0` |

### 开发模式（前端热更新）

```bash
# 终端 1：后端
uv run crawagent start

# 终端 2：前端
cd web && npm install && npm run dev
# → http://127.0.0.1:5173（/api 与 /ws 自动代理到 8006）
```

## 四、第一次对话

打开 WebUI，新建会话，直接发指令即可。示例：

| 场景 | 指令示例 |
|------|---------|
| 抓取单篇文章 | `抓取 https://example.com/article 的正文` |
| 列表页条目 | `列出 https://example.com/list 上所有文章标题和链接` |
| 多页列表一次抓 | `抓取 https://example.com/list 全部分页，每页都要` |
| 下载视频 | `下载这个 B 站视频 https://www.bilibili.com/video/BVxxx` |
| 抓取小说 | `抓取这本微信读书的全部章节 https://weread.qq.com/...` |
| 整站深抓 | `深度抓取 https://docs.example.com 整站文档` |

Agent 会自主决定调哪个工具、要不要换策略、要不要写自定义脚本，全部完成后一次性汇总结果。

## 五、首次安装清单（完整）

1. 安装 Python 3.11+ 和 Node.js 18+
2. `uv sync` 核心依赖
3. `uv sync --extra api --extra browser` 完整安装
4. `playwright install chromium` 浏览器二进制
5. 创建 `.env`，填 `OPENAI_API_KEY`
6. （可选）`BILIBILI_COOKIE` 全局 B 站认证
7. （可选）`LANGSMITH_API_KEY` 开启链路追踪
8. WebUI：`cd web && npm install && npm run build`
9. （可选）`FFMPEG_PATH` B 站视频下载需要 ffmpeg 合并音视频
10. （可选）分布式：`uv sync --extra dist`，启动自动拉起嵌入 Redis
11. （可选）Android 逆向：`pip install frida frida-tools`
