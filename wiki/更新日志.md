## v2026.09 — 分布式爬虫 + Android 逆向补齐

发布日期：2026-09-14

### 新增

- **分布式爬虫（全套）**
  - Redis checkpointer：会话状态可跨进程共享，支持多 worker 协同
  - 嵌入 Redis：`uv run crawagent start` 时自动检测 / 下载 / 启动 Redis 子进程，无需用户手动安装
  - 任务队列：Redis ZSET 优先级队列 + BZPOPMIN 原子领取 + 心跳 TTL 崩溃恢复 + 自动重投
  - Worker 管理：独立进程注册/心跳/退出清理，支持多机部署
  - REST + WS：`/api/dist/tasks` 提交/查询/取消任务，`/ws/dist/{task_id}` 实时事件流
  - 后端默认仍为 SQLite checkpointer（零侵入热路径），分布式按需开启

- **Android 逆向（frida hook）**
  - 6 个工具：`list_adb_devices` / `install_apk` / `push_file` / `frida_hook_function` / `frida_dump_so` / `frida_bypass_ssl_pinning`
  - 内置 SSL pinning 绕过脚本（社区成熟片段）
  - 工具按需调用 frida CLI（subprocess），不强制 Python 依赖

- **System Prompt 补全**
  - 工具清单补齐至 43 项（含 `recommend_scripts` / `read_skill`）
  - 新增"分布式任务队列"和"Android 逆向 / Frida Hook Workflow"指引段

### 增强

- `save_executor` 在数据含图片 URL 字段时自动下载（images/image_urls/thumbnails 列表或 image/image_url/cover 单值，大小写不敏感）
- 图片懒加载站点自动识别并切浏览器渲染抓取真实 URL
- 4xx SPA 页面：等待客户端路由完成后，若渲染内容有效（>500 字符且 title 不含 404）则覆盖状态为 200
- LLM 适配器：deepseek / zhipu / openai 三家按模型名前缀路由，思考参数（thinking.type、reasoning_effort）只传兼容方
- LLM 调用失败重试：连接/超时/429/5xx 指数退避重试 3 次
- 上下文管理：token 达上限时用 LLM 摘要旧消息（摘要失败兜底截断）
- 上下文 token 用量通过 API 暴露供前端展示
- 中间件同步 + 异步双实现（`wrap_model_call` / `awrap_model_call`），确保 LangGraph 上下文内均生效
- Thread ID 通过 `ContextVar` 可靠传递

### 变更

- 滑块验证码硬规则从 System Prompt 移除，改为非强制建议，释放 AI 自主尝试空间
- `ScriptForcer` 中间件自动拦截机制降级为非强制建议
- `langgraph-checkpoint-redis` 版本约束修正为 `>=0.5.2`（旧约束 `>=2.0.0` 不存在该版本）
- `frida` / `frida-tools` 不写入 `pyproject.toml`（其 `websockets` 约束与主环境冲突），改由用户按需 `pip install frida frida-tools`

### 修复

- `test_session_export_json` 测试：mock 新的 `get_meta_conn`
- `test_discover_tools_finds_core_count` 测试：工具数期望从 30 更新为 43

### 工具数变化

- 内置工具：30 → 43（新增 6 个 Android + 已补齐的 recommend_scripts / read_skill 等）

## v2026.08 — 基础能力成型

发布日期：2026-08-30

### 新增

- LLM 驱动的自主爬虫 Agent 框架（LangChain + LangGraph + DeepSeek）
- 22 个内置工具：crawl_webpage / browse_and_crawl / extract_content / extract_list / save_record 等
- 6 个爬虫攻略技能：bilibili-grab / douyin-grab / wallpaper-sites / weread-grab / batch-crawl-playbook / custom-script-recipes
- 浏览器渲染（Playwright）+ 字体解密（番茄小说 PUA 加密）
- MCP 协议扩展：fetch / playwright / anything-analyzer（自研抓包分析）
- Vue 3 + WebSocket 流式 WebUI，token 级输出 + 工具轨迹 + 事件日志断线重放
- 会话持久化（SqliteSaver by thread_id），重启后继续聊

## 升级指引

从旧版本升级时：

1. 先看本日志对应版本的「变更」段，评估是否需要适配
2. 同步依赖：`uv sync --extra api --extra browser`（分布式再加 `--extra dist`）
3. 检查 `.env` 是否需要新增字段（参考 `.env.example`）
4. 跑冒烟测试：`uv run pytest tests/ -v`
5. 启动验证：`uv run crawagent start`，看启动日志有无报错
