# 02 · 核心概念

> 理解 CrawAgent 怎么跑起来：Agent 循环、中间件、置信度升级、站点档案、技能扩展。

## 一、Agent 自主循环

CrawAgent 的核心是一个 LLM 驱动的自主循环：

```
用户输入
   ↓
LLM 决策（用不用工具？用哪个？）
   ↓
执行工具
   ↓
检查结果（够不够好？要不要换策略？）
   ↓
继续循环 / 返回汇总
```

与"传统爬虫脚本"的区别：**不需要为每个站写代码**。

- 通用站：靠工具组合 + 置信度自动升级
- 刁钻站（字体加密、CSS 卡片、强反爬）：Agent 现场写 Python 脚本攻克，成功脚本存进"站点档案"下次复用

### 工具调用判断（TOOL USE JUDGMENT）

多数对话轮次**零工具调用**。只有用户请求包含"可立即执行的动作"才进工具循环：

- **调工具**：URL + 动作动词（crawl / fetch / extract / download / save）、明确查库指令
- **不调工具**：问候、概念问题、策略讨论、代码求助、从历史里选序号
- **默认不调**：拿不准时先文字追问

## 二、双中间件

Agent 装两个中间件，各管一件事：

### 1. TrimHistoryMiddleware（token 裁剪）

- **管什么**：传给 LLM 的历史消息膨胀
- **怎么做**：超 token 上限时一次性淘汰到 max/2，此后窗口固定
- **关键**：**不污染**持久化的完整 state——只是给 LLM 看的视图被裁剪，数据库里完整保存
- **优化**：旧消息用 LLM 摘要替代直接截断（摘要失败兜底截断）

### 2. ScriptForcerMiddleware（防死循环）

- **管什么**：Agent 卡在工具失败循环里
- **怎么做**：
  - 连续 3 次工具失败 → 追加 SystemMessage 强制改用 `run_custom_script`
  - 总调用 30 次上限 → 强制输出最终答案
- **关键**：强制消息**追加到末尾而非插头部**，否则会打碎 LLM prompt cache 前缀

> 注：v2026.09 起，ScriptForcer 的自动拦截机制降级为非强制建议，给 AI 自主尝试留空间。滑块验证码硬规则同步移除。

## 三、置信度自动升级

提取结果会打分（0-100），低于 60 加 `[LOW CONFIDENCE]` 标记：

```
静态 HTTP 抓取 → 置信度评分
                    ↓
              <60 分 [LOW CONFIDENCE]
                    ↓
         自动切 Playwright 浏览器重抓（零 LLM 成本）
                    ↓
              重新提取
```

规则启发式，不调 LLM，免费升级。列表页有类似硬规则：`extract_list` 返回 <5 条 → 静态 HTML 是 JS 渲染的，切浏览器重抓。

## 四、站点档案（Site Profile）

首次成功后保存策略 / 脚本 / Cookie，下次同站直接复用：

| 字段 | 说明 |
|------|------|
| `origin` | 站点根域 |
| `strategy` | 策略：`crawl_webpage` / `browse_and_crawl` / `weread_cookie` / `wallpaper` / `social_media` / 自定义 |
| `script` | 成功的自定义脚本（带 script 时直接 `run_custom_script` 执行） |
| `cookies` | 站点级登录凭据（如微信读书 `wr_vid` + `wr_ssk`） |
| `notes` | 备注 |

工作流：

```
爬新站 → 先查 list_site_profiles(origin)
              ↓
         命中 → 按保存的策略执行（带 script 直接 run_custom_script）
         未命中 → 走完整分析流程 → 成功后 save_site_profile 存档
```

## 五、技能扩展（SKILL.md）

`skills/` 目录约定式加载，兼容 Claude/Trae 的 SKILL.md 格式：

```
skills/<skill-name>/
  SKILL.md          ← frontmatter(name, description) + 正文
  references/*.md   ← 可选，read_skill(name, ref=...) 按需读取
```

- **索引注入**：Agent 构建时把每个技能的 name + description 拼进 system prompt（约 1KB，prompt cache 友好）
- **正文按需**：任务命中时 LLM 调 `read_skill(name)` 读全文（截断 30000 字符），渐进披露，不膨胀每轮上下文

内置技能包（6 个）：B站 / 抖音 / 壁纸站 / 微信读书四个站点攻略 + 批量抓取总配方 + run_custom_script 配方库。

详见 [03-工具与技能总览](./03-工具与技能总览.md#技能包)。

## 六、会话持久化

- **按 thread_id 存**：thread_id = session_id，每会话独立
- **默认 SQLite**：`data/sessions.db`，进程重启后可恢复对话
- **可选 Redis**：分布式模式启用后，会话状态可跨进程共享，支持多 worker 协同
- **会话归档**：删除前自动归档 JSON 到 `logs/`

## 七、流式 WebUI

- **token 级流式**：WebSocket 推送 LLM 输出，逐字显示
- **工具轨迹**：可折叠展示每步工具调用
- **推理过程**：可折叠展示思考内容
- **事件日志重放**：每轮事件 append 到内存日志，WS 断线重连按 cursor 从 0 重放，`done` / `error` 收尾事件永不丢失
