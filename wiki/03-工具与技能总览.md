# 03 · 工具与技能总览

> 知道能用什么工具、什么技能、什么 MCP，以及怎么加自己的。

CrawAgent 共 43 个内置工具 + 6 个技能包 + 3 个 MCP server + 第三方插件规范。

## 一、工具分类总览

### 基础爬取

| 工具 | 用途 |
|------|------|
| `crawl_webpage` | 静态 HTTP 抓取 HTML（不渲染 JS） |
| `browse_and_crawl` | Playwright 浏览器渲染（SPA/JS 动态页/字体加密） |

### 内容提取

| 工具 | 用途 |
|------|------|
| `extract_content` | 详情页提取标题 + 正文，输出 Markdown（含置信度评分） |
| `extract_list` | 列表页条目提取（标题 + URL，自动过滤导航/页脚） |
| `extract_list_paged` | 静态多页列表一次抓全（自动翻页 + 跨页去重） |
| `ask_user` | 向用户发起交互式选择题（聊天页按钮作答） |

### 存储与查询

| 工具 | 用途 |
|------|------|
| `save_record` | 存入 SQLite |
| `list_crawled_resources` | 查历史抓取记录 |
| `search_knowledge` | 全文检索知识库正文（FTS5 trigram + bm25） |
| `save_to_file` | 存本地文件（md / txt / json → output/） |
| `download_images` | 批量下载图片/视频（含防盗链 referer） |

### 社媒（抖音 / B站）

| 工具 | 用途 |
|------|------|
| `extract_social_media` | 元数据/评论/媒体 URL（免登录） |
| `download_social_media` | 下载视频/音频/封面/评论（B站自动合并音视频） |

### 壁纸 / 图片站

| 工具 | 用途 |
|------|------|
| `extract_wallpaper_list` | 壁纸列表提取（处理 CSS background-image 卡片） |
| `wallpaper_detail` | 单个壁纸详情（类型/分辨率/全部 URL） |

### 微信读书（需 Cookie）

| 工具 | 前置条件 |
|------|---------|
| `list_weread_chapters` | 站点档案配 Cookie（wr_vid + wr_ssk） |

### 站点档案

### 自定义脚本（兜底武器）

| 工具 | 用途 |
|------|------|
| `run_custom_script` | Agent 现场写 Python 脚本执行，专治内置工具搞不定的站 |

### 高级工具（预装库包装）

## 二、技能包清单

`skills/` 目录内置 6 个攻略技能：

| 技能 | 覆盖场景 |
|------|---------|
| `bilibili-grab` | B站视频/弹幕/评论抓取 |
| `douyin-grab` | 抖音视频/图集抓取 |
| `wallpaper-sites` | 壁纸站批量抓取 |
| `weread-grab` | 微信读书章节抓取 |
| `batch-crawl-playbook` | 批量抓取总配方（30 章/50 张同类条目） |
| `custom-script-recipes` | run_custom_script 阶梯配方 |

工作方式：Agent 构建时把 name + description 拼进 system prompt（约 1KB），任务命中时 LLM 调 `read_skill(name)` 读全文，渐进披露。

## 三、MCP 接入

`.env` 的 `MCP_SERVERS`（JSON 数组）支持任意多 server。当前接入三个：

| server | 传输 | 提供 |
|--------|------|------|
| anything-analyzer（自研） | streamable_http | 抓包分析 30 工具 |
| fetch（官方 mcp-server-fetch） | stdio | `fetch` 网页转 Markdown |
| playwright（微软 @playwright/mcp） | stdio | 24 个 `browser_*` 工具 |

特性：

- **故障隔离**：单个 server 连不上只跳过它自己，不影响其它
- **缓存**：成功的 server 按配置指纹缓存握手结果，进程内只握手一次
- **`{project_root}` 占位符**：stdio 的 command/args 可引用项目 venv 解释器
- **聊天即加 MCP**：`add_mcp_server` 工具让你在对话里直接加 server（需 ask_user 确认）

## 四、插件规范

第三方插件放项目根 `plugins/`，目录约定：

```
plugins/<plugin-name>/
  plugin.json           ← manifest：name 必填
  tools/*.py            ← 工具模块（@tool 自动进 Agent 工具表）
  skills/*/SKILL.md     ← 技能包（自动进技能索引）
  requirements.txt      ← 可选 pip 依赖清单
  README.md
```

CLI 管理：

```bash
crawagent add-tool my_plugin              # 从脚手架创建新插件包
crawagent add-plugin D:/path/to/plugin    # 从本地目录接入
crawagent add-plugin https://github.com/x/y.git  # 从 git 仓库接入
crawagent plugins                         # 查看已装插件
```

仓库自带示例插件 `plugins/example-rss/`。

## 五、扩展点

### 加新工具

1. 在 `crawagent/tools/` 新建 `.py` 文件
2. 写 `@tool` 装饰器 + docstring（docstring 即 LLM 看到的工具规范）
3. 在 `registry.py` 注册（自动发现，按需加 metadata）
4. 在 `system.md` 工具清单追加条目（让 LLM 知道何时调用）
5. 跑测试 `uv run pytest tests/ -v`

### 加新技能

1. 在 `skills/` 新建 `<name>/SKILL.md`
2. frontmatter 写 `name` + `description`（≤200 字符）
3. 可选：`references/*.md` 子文档（`read_skill(name, ref="...")` 读取）
4. Agent 重启自动索引

### 加新中间件

参考 `crawagent/graph/middleware.py` 的 `TrimHistoryMiddleware`，实现同步 + 异步双版本（`wrap_model_call` / `awrap_model_call`），确保 LangGraph 上下文内均生效。

### 加新 MCP server

聊天里直接说"加一个 xxx MCP server"，Agent 调 `add_mcp_server`，确认后下轮生效。或手改 `.env MCP_SERVERS`。

### 换 LLM

在 WebUI 设置页「模型」维护 `LLM_PROVIDERS` JSON 数组，按服务商共享 Key。适配器自动按模型名前缀路由（deepseek / zhipu / openai），思考参数只传兼容方。
