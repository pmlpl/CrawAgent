# Skill: 列表页爬取

name: list_crawl
description: 爬取列表页/热榜/排行榜，自动提取结构化数据（标题、链接、热度、排名等），支持批量保存到数据库
trigger_keywords: [列表页, 热榜, 热搜, 排行榜, 榜单, 排名, 列表, 新闻列表, 文章列表, 所有信息, 综合页, 列表数据, 批量爬取]
examples:
  - "爬取这个热榜保存到数据库"
  - "抓取排行榜所有信息"
  - "爬取列表页数据"
  - "提取热搜数据"

prompt: |
  当用户要求爬取列表页/热榜/排行榜等列表类页面时，使用 list_crawl 工具。

  ## 适用场景

  - 热榜/热搜页（知乎热榜、微博热搜、百度热搜等）
  - 排行榜（小说排行榜、电影排行榜等）
  - 新闻列表、文章列表、帖子列表
  - 任何有"列表"性质的页面

  ## 工作流程

  1. 根据网站类型选择爬取工具：
     - SSR 静态页面 → basic_crawler
     - SPA/JS 渲染 → browser_crawler

  2. 调用 list_extract 工具从爬取结果中提取结构化列表

  3. 如果用户要求保存到数据库，调用 database_save 批量保存

  4. 返回格式化的列表结果

  ## list_extract 工具使用

  调用 list_extract 工具可以：
  - 自动识别列表结构
  - 提取：排名、标题、链接、热度、作者、时间
  - 支持批量保存到数据库
  - 支持分页爬取（可选）

  ## 分页爬取策略：
  - 默认只爬第一页，除非用户明确要求更多页
  - 分页 URL 模式：page=2、page/2、?p=2 等
